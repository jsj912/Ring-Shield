Fraud Terms Glossary

Ring / Syndicate:

A detected closed-loop or coordinated cyclic transaction network engineered to obfuscate funds flow.

Seed Transaction:

The primary trigger transaction identified by rule detectors that initiated the ring graph expansion.

Conservation Closure:

Percentage of funds retained within the ring graph without leaking into external out-of-network accounts.

SHAP Value:

Shapley Additive exPlanations measuring feature contribution to the machine learning model's risk score.
